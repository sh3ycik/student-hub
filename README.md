# Student Hub

Особиста сторінка студента: розклад, завдання, таймер Pomodoro, оцінки та нотатки. Працює без сервера, дані зберігаються у браузері.

## Як завантажити на GitHub Pages
1. Створіть репозиторій на github.com (наприклад, `student-hub`), позначте **Public**.
2. Натисніть **Add file → Upload files** і перетягніть `index.html`, `style.css`, `script.js`, `README.md`. Натисніть **Commit changes**.
3. Відкрийте **Settings → Pages**. У розділі **Branch** виберіть `main` і папку `/ (root)`, натисніть **Save**.
4. Через 1–2 хвилини сайт буде доступний за адресою `https://ВАШ_НІК.github.io/student-hub/`.

## Можливості
- Розклад за днями з редагуванням, підсвіткою поточної пари та підказкою «Наступна пара»
- Завдання з дедлайнами, пріоритетами, фільтрами та прогресом
- Таймер Pomodoro з налаштуванням тривалості
- Оцінки за 12-бальною шкалою і середній бал
- Нотатки з автозбереженням
- Тема (світла, темна, авто), акцентний колір, ім’я, експорт та імпорт даних
